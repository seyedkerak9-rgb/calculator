# Calculator

A responsive, dependency-free Persian calculator built with HTML, CSS, and JavaScript.

The user interface is available in four languages: Farsi, English, Italian and German. Choose the desired language from the list next to the logo; The direction of the page and the number display format also change according to the language.

## Facilities

-
Addition, subtraction, multiplication and division with the possibility of chaining calculations
- Percentage, changing the number sign and deleting the last digit
- Error display when dividing by zero
- Recording the last four calculations and the possibility of choosing the result again
- Support for keyboard and mobile screens
- Can be published directly on GitHub Pages

## Execution

Open the index.html file in the browser.
For easier development, you can use the Live Server plugin in Visual Studio Code.

## Keyboard keys

| key | Performance
| --- | --- |
| `0` to `9` Enter the number |
| `+`, `-`, `*`, `/` | Select operator |
| `.` or `,` | Enter the auditor
| `Enter` or `=` | Calculate the result
| ``Backspace'' | Delete the last digit
| ``Escape'' | Clear calculation
| `%` | Convert number to percentage

## Publishing on GitHub Pages

1. Place these four files in your GitHub repository.
2. In the repository, go to **Settings → Pages**.
3. Select the option to publish from the desired directory (usually ``main'' and the ``/root'' folder).
4. After saving, the website address will be displayed in the same section.
The Vazirmatn font is downloaded from Google Fonts; If it cannot be accessed, the device's alternative font will be used.
